ModelFetcher

New here? What is this and what do I pick?
i
ModelFetcher downloads AI models from Hugging Face and Civitai to your PC.

Four steps: choose a folder, paste a model name, check the files we selected for you, press Download.

Models come in two common shapes, and the tool tells you which one you have:

  • GGUF (name usually ends in -GGUF): many files that are all the same model in different sizes. You pick one. For LM Studio, Ollama, llama.cpp, KoboldCpp.
  • Standard / safetensors (for example Qwen/Qwen2.5-0.5B-Instruct): a set of files that belong together. You download all of them. For Python (transformers) and similar tools.
  • Civitai (image models: checkpoints, LoRAs, embeddings): usually one main file, which is pre-selected. For ComfyUI, Forge, A1111 and similar.

Not sure? Just leave the pre-selected files ticked. They are the sensible default.
